# Known Fragile Areas

## "Do Not Break" Principles
- Do not remove canvas tags (`<canvas>`) or their associated Javascript. The ambient particles and starfield effects are core to the brand.
- Do not normalize typography if it removes the "Impact" font. Hardcoded font declarations exist for a reason.

## Major Fragile Files
- `sections/main-product.liquid`: This file is exceptionally large (2800+ lines). It contains custom canvas implementation (`ak-product-field`), deeply nested CSS overrides for transparency, and layout hacks. Product gallery uses `"stacked"` layout + `"lightbox"` zoom (settled 2026-04-05 after testing thumbnail/hover/stacked/lightbox combos). Stacked shows all images vertically; lightbox enables click-to-zoom. Product info block order (settled 2026-04-05): title → price → variant_picker → quantity_selector → buy_buttons → description → share. Empty `custom_liquid_KbTzPh` block removed. Purchase panel CSS polish (2026-04-05): price scaled up, Add to Cart promoted to filled primary CTA, description contained with separator, spacing rhythm refined, gallery grid tightened. All in `{%- style -%}` block — revert by removing the "PURCHASE PANEL POLISH" CSS section.
- `layout/theme.liquid`: Contains heavy inline CSS defining color schemes and CSS variables, as well as multiple app embeds. Changing script load order here is risky. As of 2026-05-18, this file also carries the global black-background safety net (`html, body { background:#000 !important }` + `#MainContent { background: transparent !important }` + `#MainContent .gradient { background: transparent !important; background-image: none !important }`) inserted as a `<style>` block immediately after the existing `{% endstyle %}` Dawn color-scheme block. **This package is load-bearing** for every template that disables `ak-collection-bg`. Removing it would re-expose Dawn's body-via-scheme white. Future edits to this `<style>` block must preserve all three rules with `!important`.
- `templates/page.mystery-box.json`: Contains the Vercel iframe embed wrapped in a highly specific locked layout (`ak-mb-wrap`, `ak-mb-canvas`).
- `sections/ak-collection-bg.liquid`: Originally a particle/starfield canvas section, but **also injects** a 3-rule CSS package (`html, body { background:#000 !important }` + `#MainContent { background: transparent !important }` + `#MainContent .gradient { background: transparent !important; background-image: none !important }`) that historically made the 22 templates referencing this section render solid black. As of 2026-05-18 the same 3-rule package is mirrored globally in `layout/theme.liquid` so the black-background fallback survives the section being disabled on individual templates. **Critical rule for future particle-removal lanes: never disable `ak-collection-bg` on any template unless the 3-rule package in `layout/theme.liquid` is verified present.** Removing it from a template without the global package will re-expose Dawn's body white. Removing the global package while any template still has `ak-collection-bg` disabled will also re-expose white on those templates. The two are interdependent until either all 22 templates re-enable the section or the section file itself is deleted (not planned).

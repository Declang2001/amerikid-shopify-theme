# Runtime Test Checklist

Use this checklist to verify the storefront after any approved change is implemented.

## Core Pages
- [ ] **Homepage:** Verify load speed, layout, and that PageFly elements render correctly.
- [ ] **Collection Pages:** Check grid layout, image loading, and that the Impact font is still applied where expected.
- [ ] **Product Pages:** Check `main-product` layout. Ensure the background starfield canvas (`ak-product-field`) renders and animates. Verify Add to Cart functionality. **Count canvases: should not increase.**
- [ ] **Archive Page:** Verify cards read as cassette cases — visible dark shell housing around cover art, subtle plastic sheen, hinge line on left edge, spine-style tabs on trailing cards. Verify stack composition preserved (5 trailing strips visible). Verify tap navigates, drag works, arrows work, keyboard works. Verify title labels readable over inset art. Verify mobile 375/320px (reduced padding, smaller tabs).
- [ ] **Life/Style Page:** Verify particles fill entire viewport behind all content (not just inside modules). Verify no dead black gaps between Adventures, Kid Radio, and Channels sections. Verify module content readable over particle background. Verify glass card styling on video cards still present (borders, shimmer, hover lift, playing states). Verify Adventures title ambient flicker animation running. Verify Kid Radio title ambient signal pulse running. Verify Channels title animation unchanged. Verify Channels 3D tilt on desktop. Verify YouTube embeds load and play in both Adventures and Kid Radio. Verify wave bar visualizer on Kid Radio. Verify ak-top particles still render above background canvas. Verify ak-footer renders cleanly at bottom. Verify mobile 375/320px — no overflow, text readable, modules flow seamlessly. Verify reduced-motion: background canvas hidden, title animations disabled. Verify no layout shift. Verify no new console errors. **Count canvases: should be 5 (background + ak-top + 3 modules).**
- [ ] **Custom Landing Pages:** Spot check pages like "The Collective" or specific collection drops for missing assets.
- [ ] **Mystery Crate Page:** Verify the iframe loads the Vercel app. **Check console for crate.glb status.** Verify display shell: frame should read as a dark matte monitor housing with subtle top-to-bottom gradient, asymmetric bezel (8px top/sides, 14px chin on desktop; 6px/10px on mobile), squared corners, subtle top-edge bevel highlight, and dim green power LED centered in chin area. Iframe content should fill the screen area inside the bezel with a slight recess (inset shadow). Verify release overlay: before release time, the lock overlay should cover the screen area inside the bezel (not the bezel itself, not the full viewport). Lock card corners should match the shell (squared, not rounded). Nav/header (ak-top) must remain accessible. Footer must remain accessible. Countdown timer (DD:HH:MM:SS) should be visible inside the lock card. Timer should tick every second. Interaction with iframe should be blocked. To test auto-unlock: temporarily set `TARGET_UTC` to a past time in `ak-mb-release.liquid` and reload — lock overlay should not appear. To test live unlock: set target ~10 seconds in the future and watch the lock hide. Verify mobile 375/320px (smaller digits, thinner bezel, card fits). After release date (2026-04-09T07:00:00Z / Thu Apr 9, 12:00 AM PT): overlay should not appear at all.

## Navigation and Interactivity
- [ ] **Mobile Menu / Drawer:** Click the "MENU" label. Ensure the drawer opens and closes properly. Check that the close "X" is positioned correctly.
- [ ] **Header/Footer:** Check for missing elements or misaligned global navigation. Verify ak-footer Back to Top button renders on Life/Style, Products, Archive, Narrative, Bad Music, Mystery Box, and Clubhouse pages. Verify footer does NOT appear on cart, product, or individual collection pages. Verify hover shows magenta glow halo + ring lift + arrow brighten. Verify click triggers pulse animation + smooth scroll to top. Verify reduced-motion: no animations, instant scroll.
- [ ] **Cart Drawer / Cart Page:** Add an item to the cart. Verify the AJAX cart drawer slides out without breaking the layout.
- [ ] **Animations:** Ensure hover effects (glows, neon borders) on buttons and the continuous wrapper glow in the nav still function.

## Technical Checks
- [ ] **Console Errors:** Open browser developer tools. Ensure no **new** 404 errors or Javascript errors are present. Monitor `video-player` registry error.
- [ ] **Builder Regressions:** Verify that PageFly pages still function. Check that removing EComposer/GemPages remnants didn't break global styles (if applicable).
- [ ] **Asset Loading:** Check Network tab for `cdn.ecomposer.app` or `gp-global.css` calls.
- [ ] **Responsive Design:** Resize the viewport down to 320px. Ensure neon borders, canvases, and text do not break the horizontal bounds.
